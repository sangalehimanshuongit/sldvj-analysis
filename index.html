Help and messages
MessageWhat to do
Could not load the analysisCheck the internet connection, then reload the page. On a strict network, try another browser or network once. After that, the browser keeps a copy.
Not a LabChart .adicht fileAdd the .adicht file that LabChart saved, not an export or a shortcut.
Could not read the fileThe file is damaged or comes from another set-up. Save it again from LabChart.
Static-balance file?The file has no EMG or accelerometer channels. Remove it from the list.
No drop jump was foundNo record holds a complete trial (empty plate, contact, flight, landing held for at least 1 s).
Same codes as another fileTwo files have the same participant and session codes. Correct one of them.
Check: …The analysis ran, but a trial needs a look. Open the report and read its Detailed view.
Out of memoryClose other tabs, reload the page and add fewer files at a time.

The page analyses the force plate, EMG and accelerometer signals. It does not analyse video, knee angle or static balance. Closing the tab clears every file and result from the browser.
