# SL-DVJ Analysis

A web page that analyses single-leg drop vertical jump recordings (LabChart `.adicht`: force plate, EMG and accelerometers).

The analysis runs inside the browser with [Pyodide](https://pyodide.org). Files stay on the user's computer: the page has no upload function, its content security policy blocks connections to other sites, and it works offline once loaded. This repository holds code only, no data.

Open the page: https://sangalehimanshuongit.github.io/sldvj-analysis/
